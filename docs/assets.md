# 素材来源

全部六张角色 PNG 由本项目开发过程中使用的内置 imagegen 生成，白发、紫瞳、白金/淡紫龙娘为统一设计。图片保留生成器返回的原始 alpha，未将图片改为低清占位图。

- chibi / full：初始 Q 版和全身。
- medium / xhigh / max：参考全身形态生成的持书、施法和龙后形态；提示摘要见 assets/v1.1-prompts.md。
- ultra：v1.4 参考 Max 的细节质量和旧 Ultra 重绘最终星冠巨翼形态；完整提示词见 assets/ultra-v1.4-prompt.txt。

Max 不因 Ultra 升级而改变。图中灯光、星轨、粒子和动态网格由运行时代码绘制。assets/SHA256SUMS.json 记录本次源素材哈希，可用于核验。
