# 验证记录和实际边界

## 可复现的离线验证

运行 `scripts/verify.ps1`。它构建程序并执行：

1. 合法聊天导航、缓存聊天切换、主页/设置/远程路由、错误 UUID、辅助窗口、超大输入及无关后台事件的识别。
2. 六档映射、未知档位暂停、点击回应结束，以及写设置/发消息/中断/恢复等请求在连接之前被拒绝。
3. 六种形态在三个时刻的非空渲染及显著像素变化，生成深浅背景对照图。

不读取开发者的真实聊天、配置或 API Key，不要求桌面端启动。报告及渲染图片写入忽略目录 out，不随源码提交。

## 2026-10-30 本机历史验证

- 已安装的 v1.4 成功连接当前本地聊天；自动跟随来自准确的侧栏导航记录。
- 用户在 v1.3 安装后确认侧栏切换时标题跟随、点击有回应；预览滑块、点击和拖动进行了实际界面验证。
- 本机五次断开/重新连接后读取成功，验证过程 config.toml 哈希不变。
- v1.3 安装前后桌面 exe、app.asar 和配置哈希一致。
- v1.4 对前五档素材比较 SHA-256，并对三个相同时间点的实际原生渲染比较像素，均完全不变；Ultra 单独重绘并检查透明 alpha。
- 登录计划任务在普通用户会话独立运行；程序单实例，不依赖发起构建的终端。

这些是当时本机结果，不表示其他机器或后续版本已验证。

## 未验证或不支持的场景

- 未强行退出正在工作的桌面端做完整托盘退出/再启动测试，也未进行 Windows 重新登录实测。已验证独立任务启动及连接重建，不能把它们等同于完整重启验证。
- 未实际安装一个未来桌面版本做升级验收，不保证内部协议永久兼容。
- 未做长期压力、实体多显示器切换及所有 DPI/显卡组合验证。
- 自动跟随不支持多窗口歧义、远程聊天、非主窗口及未知路由/协议；遇到这些情况会等待而非猜测。
- 原生思考滑块提交前的临时位置不会逐点跟随。纯视觉预览滑块立即响应，且不修改任何思考设置。
